# CSC209 Web Programming Portfolio

## Overview
This repository contains my work for CSC209 Web Programming course, showcasing various web development projects, assignments, and exercises completed throughout the semester. This portfolio shows my skills in HTML, CSS, JavaScript, and PHP, and how I build clean, functional websites using solid web development practices.

### Main Projects
- **MysteryHub** - Final project: A comprehensive web application
- **WBPortfolio** - Web Portfolio project
- **Midterm Projects**

  - Midterm Part 2

### Weekly Assignments
The repository is organized by weeks, containing both homework assignments and weekly exercises:

#### Weekly Homework (Hwks)
- Homework 1-9, covering various web development concepts and implementations
- Each homework assignment is self-contained with its own start page

#### Weekly Assignments
